Få en renere YouTube-opplevelse på LG TV.

Windows-program som setter opp YouTube uten reklame på en LG-TV (webOS) og holder Developer Mode i live, så appen ikke slutter å virke. Programmet leder deg gjennom oppsettet trinn for trinn.

Uoffisielt program, ikke tilknyttet LG eller YouTube. Bruk på eget ansvar.
## Dette kan programmet
- Finner TV-en på nettverket og kobler til
- Installerer YouTube uten reklame (åpen kildekode, youtube-webos)
- Fornyer Developer Mode-økten automatisk hver uke
- Påminnelser når TV-telleren må nullstilles
- Kan installere andre apper fra egen fil
- Norsk og engelsk, tre temaer (blått, mørkt, lyst)

## Les dette før du laster ned
- **Krav:** Windows 10 eller 11 (64-bit). LG-TV med webOS og Developer Mode-appen (gratis LG-konto). PC og TV på samme nettverk. Testet på webOS 4.10; andre modeller er ikke testet.
- **Lisens:** 30 dagers gratis prøvetid, deretter trengs en kode (pris 100 kr, ca. 10 EUR). Betal med Vipps (Norge) eller PayPal (alle land, vanligvis også med kort uten PayPal-konto). Koden gjelder ett program på én PC.
- **Windows-advarsel:** Programmet er ikke kodesignert, så Windows kan vise «Windows beskyttet PC-en din». Trykk **Mer info** og så **Kjør likevel**. Det skjer med alle nye programmer uten betalt signatur.
- **Personvern:** Programmet sender ikke data til meg. Innstillinger og logg ligger på din egen PC.


## Slik installerer du
1. Last ned filen som slutter på **_Setup.exe** (under «Assets» nederst).
2. Dobbeltklikk den og velg mappe.
3. Start programmet fra Start-menyen eller skrivebordet.
